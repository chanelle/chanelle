# Hi, I’m Chanelle 👋🏾

I build things where **AI, product, research, accessibility, and human behavior** collide.

Most of my work starts the same way: I notice something that isn’t working quite right, pull at the thread, and eventually build the thing I wish had existed.

Right now I’m experimenting with:

- human-centered AI evaluation
- agent systems that know when *not* to act
- tools for neurodivergent workflows
- turning research and judgment into reusable systems
- occasionally making something weird just because I want to see if it works

## A few things I’m building

**[90/10 Agent Benchmark](https://github.com/chanelle/90-10-agent-benchmark)**
Testing whether AI systems can actually reduce human cognitive load instead of creating more work.

**[Beta’s AI Lab](https://github.com/chanelle/betas-ai-lab)**

**[Dala](https://github.com/chanelle/dala)**

**[Career Pivot Navigator](https://github.com/chanelle/career-pivot-navigator)**

Then I design what should have existed.

That might turn into a product, a prototype, a research system, a framework, an article, or something I didn’t have a name for when I started.
